# Quanto Veio? V4 — Gerador de cards

Este pacote preserva a V3 e acrescenta um gerador de cards em modal com PNG Feed (1080 × 1620) e Stories (1080 × 1920). Os valores e séries anuais são lidos do conjunto D incorporado ao index.html. A geometria é solicitada ao IBGE; o QR Code utiliza qrcodejs via CDN e, se indisponível, é substituído pela URL textual. Não há atualização automática da CGU.
