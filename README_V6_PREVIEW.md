# Quanto Veio? — V6 / Design Preview

Protótipo navegável e funcional baseado integralmente na V5.4.

## O que mudou
- Nova abertura editorial com busca em destaque, exemplos rápidos e explicação do fluxo de investigação.
- Ordem de leitura: busca → resultado municipal → atlas → ranking → metodologia.
- Resultado em largura total, com índice de navegação por panorama, evolução, emendas e documentos.
- Linguagem visual autoral: tipografia de alto contraste, linhas editoriais, cores sóbrias, sem gradientes ou cartões genéricos.
- Preserva dados, URLs, mecanismos de busca, atlas, ranking, detalhes e scripts de analytics da V5.4.

## Atenção
Este é um PREVIEW de design. Não substitua a versão pública sem validar no navegador, especialmente fluxos de busca, mapas e compartilhamento.
Abra via servidor HTTP local para que os arquivos JSON carreguem; abrir o index.html diretamente via file:// pode bloquear fetch.

## Fonte
CGU; metodologia e ressalvas preservadas da V5.4.
